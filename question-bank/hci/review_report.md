## 3. Detailed Question-by-Question Verification Matrix

### Section 1.5: Week 1 Assignment Questions (Solved)
1. **`hci_w1_q01`** (Q1, Page 9)
   - **Question**: What does HCI stand for?
   - **Options**: A. Human Computer Integration | B. Human Computer Interaction | C. High Computer Intelligence | D. Human Control Interface
   - **Key**: **B** (`opt_hci_w1_q01_b`)
   - **Explanation**: Quoted from Lecture 01_04: “the study and design of how people interact with computers and other technologies”. Verified.

2. **`hci_w1_q02`** (Q2, Page 9)
   - **Question**: Which of the following is a key component of HCI?
   - **Options**: A. User | B. Processor speed | C. Internet cable | D. Battery life
   - **Key**: **A** (`opt_hci_w1_q02_a`)
   - **Explanation**: Slide “Key Components of HCI” identifies User, Technology, and Interaction. User is central to HCI.

3. **`hci_w1_q03`** (Q3, Page 9)
   - **Question**: Which is an example of good design?
   - **Options**: A. Confusing navigation | B. Clear push/pull sign on door | C. Too many buttons | D. No feedback
   - **Key**: **B** (`opt_hci_w1_q03_b`)
   - **Explanation**: Tutorial 1 door handle example: immediately tells people what to do.

4. **`hci_w1_q04`** (Q4, Page 9)
   - **Question**: Digital transformation means:
   - **Options**: A. Converting physical processes into digital systems | B. Increasing manual work | C. Removing technology | D. Using paper forms only
   - **Key**: **A** (`opt_hci_w1_q04_a`)
   - **Explanation**: Integration of digital technologies into all areas, e.g. driving-license online form.

5. **`hci_w1_q05`** (Q5, Page 10)
   - **Question**: Which of the following is NOT a usability factor?
   - **Options**: A. Efficiency | B. Memorability | C. Network speed | D. Satisfaction
   - **Key**: **C** (`opt_hci_w1_q05_c`)
   - **Explanation**: Usability components are Efficiency, Effectiveness, Learnability, Memorability, Satisfaction. Network speed is a technical connection property.

6. **`hci_w1_q06`** (Q6, Page 10)
   - **Question**: Which principle ensures users understand possible actions?
   - **Options**: A. Feedback | B. Affordance | C. Consistency | D. Visibility
   - **Key**: **B** (`opt_hci_w1_q06_b`)
   - **Explanation**: Affordance ensures users understand possible actions just by looking at the interface.

7. **`hci_w1_q07`** (Q7, Page 10)
   - **Question**: Feedback in interaction design means:
   - **Options**: A. Removing buttons | B. System response after user action | C. Increasing storage | D. Deleting data
   - **Key**: **B** (`opt_hci_w1_q07_b`)
   - **Explanation**: Clear response provided after user action (e.g., button color change).

8. **`hci_w1_q08`** (Q8, Page 10)
   - **Question**: A cluttered interface leads to:
   - **Options**: A. Better usability | B. Faster performance | C. User confusion | D. Improved satisfaction
   - **Key**: **C** (`opt_hci_w1_q08_c`)
   - **Explanation**: Cluttered screens and too many options overwhelm the user and cause frustration.

9. **`hci_w1_q09`** (Q9, Page 10)
   - **Question**: Which of the following best describes interaction design (IxD)?
   - **Options**: A. Designing hardware components | B. Designing interactive digital systems and experiences | C. Managing databases | D. Programming languages
   - **Key**: **B** (`opt_hci_w1_q09_b`)
   - **Explanation**: Practice of designing interactive digital products, environments, systems, and services.

10. **`hci_w1_q10`** (Q10, Page 11)
    - **Question**: What is the main issue with too many features in an interface?
    - **Options**: A. Improves usability | B. Reduces cost | C. Overcomplicates user experience | D. Improves performance
    - **Key**: **C** (`opt_hci_w1_q10_c`)
    - **Explanation**: Unnecessary features make an overcomplicated interface (e.g. TV remote with dozens of unused buttons).

### Section 1.7: Week 1 Probable Practice Questions (Other)
11. **`hci_w1_p01`** (P1, Page 12)
    - **Question**: According to the lecture, HCI emerged as a field in which decade?
    - **Options**: A. 1960s | B. 1970s | C. 1980s | D. 2000s
    - **Key**: **C** (`opt_hci_w1_p01_c`)
    - **Explanation**: HCI emerged in the 1980s, influenced by computer science, psychology, and cognitive science.

12. **`hci_w1_p02`** (P2, Page 12)
    - **Question**: Which of these is the usability component that measures how easily users can return to a system after a break?
    - **Options**: A. Learnability | B. Effectiveness | C. Efficiency | D. Memorability
    - **Key**: **D** (`opt_hci_w1_p02_d`)
    - **Explanation**: Memorability = ease of returning after a break.

13. **`hci_w1_p03`** (P3, Page 12)
    - **Question**: In the lecture’s nested model, which concept is the broadest?
    - **Options**: A. Usability | B. Customer experience | C. User experience | D. Accessibility
    - **Key**: **B** (`opt_hci_w1_p03_b`)
    - **Explanation**: Usability is nested inside User Experience, which is nested inside Customer Experience.

14. **`hci_w1_p04`** (P4, Page 12)
    - **Question**: Which interaction style is described as “efficient for technical users; relies on text commands”?
    - **Options**: A. CLI | B. VUI | C. GUI | D. NUI
    - **Key**: **A** (`opt_hci_w1_p04_a`)
    - **Explanation**: CLI = Command Line Interface. GUI uses icons/buttons, VUI uses speech, NUI uses natural gestures/voice.

15. **`hci_w1_p05`** (P5, Page 13)
    - **Question**: The Boeing 737 MAX MCAS example in Tutorial 1 mainly illustrates the lack of:
    - **Options**: A. Consistency of colours | B. Aesthetic appeal | C. Visibility and feedback | D. Learnability for novices
    - **Key**: **C** (`opt_hci_w1_p05_c`)
    - **Explanation**: MCAS activated without clear feedback to pilots; lack of visibility and feedback contributed to disaster.

16. **`hci_w1_p06`** (P6, Page 13)
    - **Question**: A Braille character consists of:
    - **Options**: A. 8 dots in a 2×4 grid | B. 6 dots in a 2×3 grid | C. 4 dots in a 2×2 grid | D. 9 dots in a 3×3 grid
    - **Key**: **B** (`opt_hci_w1_p06_b`)
    - **Explanation**: 6 dots arranged in 2 columns and 3 rows, numbered 1 to 6 (Project WAYV slides).

17. **`hci_w1_p07`** (P7, Page 13)
    - **Question**: Which is NOT listed as a challenge of digital transformation?
    - **Options**: A. Digital divide | B. Skill gaps | C. Data security | D. Increased paper usage
    - **Key**: **D** (`opt_hci_w1_p07_d`)
    - **Explanation**: Digital transformation reduces paper usage; stated challenges are security, digital divide, skill gaps, privacy.

18. **`hci_w1_p08`** (P8, Page 13)
    - **Question**: Which usability-evaluation method has experts judge an interface against usability principles?
    - **Options**: A. A/B testing | B. Cognitive walkthrough | C. Heuristic evaluation | D. Surveys
    - **Key**: **C** (`opt_hci_w1_p08_c`)
    - **Explanation**: Heuristic evaluation: experts assess interface against established usability principles (Nielsen).

19. **`hci_w1_p09`** (P9, Page 13)
    - **Question**: Which guideline is named in Week 1 as the standard for web accessibility?
    - **Options**: A. ISO 9001 | B. WCAG | C. GDPR | D. IEEE 802.11
    - **Key**: **B** (`opt_hci_w1_p09_b`)
    - **Explanation**: WCAG (Web Content Accessibility Guidelines) and WAI-ARIA.

20. **`hci_w1_p10`** (P10, Page 14)
    - **Question**: An Instagram like-button that turns red when tapped is an example of which principle?
    - **Options**: A. Feedback | B. Constraint | C. Affordance | D. Consistency
    - **Key**: **A** (`opt_hci_w1_p10_a`)
    - **Explanation**: Gives immediate visual feedback confirming that the user's tap action has been registered.
